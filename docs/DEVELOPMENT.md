# 开发路线与提交约定

Git 远程：`https://github.com/YJsnz/challenge.git`。功能步骤分别提交；修复单独提交，避免把无关改动并入一个记录。原始上游、模型与数据不提交；Qt 复用文件单独保留许可。

目前代码已经覆盖：源码审计、统一接口、离线多模式、质量融合、有限遮挡跟踪、概率风险状态机、传感器适配、ROS 消息与节点、Qt 面板改造、记录与评测脚本。

当前改造后的 Qt 复用范围：

| 原模块 | 当前处理 |
|---|---|
| RadarStationMainWindow.init_ui | 保留左/中/右 2:2:1 布局方法 |
| StatusIndicator | 保留原设备指示组件，换接相机与激光状态 |
| ZoomableDraggableLabel | 保留缩放拖拽逻辑，修正逐帧刷新重置缩放 |
| FieldProjectionWidget | 28×15 比赛坐标、阵营翻转改为可配置仓储米制地图 |
| 图像更新、Qt 定时器 | 新数据接口、后台回放和 ROS signal/slot |
| 裁判通信、双倍易伤、哨兵与阵营 | 不接入工业界面 |
| 曝光增益、比赛关键点 PnP 对话框 | 不照搬；当前选择独立实机标定 JSON，SDK 控制留待实际驱动适配 |

后续必须依次完成 Linux 软件验证、实机标定/工业模型、原 B3 对照、独立 GT 评测和真实受控演示。任务完成状态以验证结果为准，不把“代码已写”直接标记成“实机通过”。
